# 项目管理验收

## 前置与版本

源码合同为Schema8/envelope3/UI5/包格式1，不等于正式实例已升级。验收前核对实际分支、HEAD、工作树、CLI/taskd身份、数据库/runtime及/ui/status；不覆盖现有修改、不自动停止正式服务。

全部测试使用明确的隔离TEST_DB、合成项目/任务和独立runtime。获准启动新服务时显式绑定172.19.10.185，访问 `http://172.19.10.185:PORT`；不可用先确认，不回退。reader隔离使用--require-local-auth，不能拿本机免认证模式证明reader安全。

准备两个合成项目P-A/P-B、P-A组件C-A、任务T-A/T-B及路径文字PATH-A/PATH-B。源码路径可不存在，不需要临时Git仓库或真实源码；所有ID/revision/version取自当前响应。证据不保存凭据/Cookie。

## 验收项

| 用例 | 操作与预期 |
| --- | --- |
| 项目创建/改名 | CLI创建、show、rename；ID不变，独立revision/History推进；同名及ASCII大小写等价名冲突；不创建Task/Session |
| 组件/源码资料 | component add；source add --directory PATH；source list/remove；只写资料和Project History，不要求路径存在、不访问/删除目录，不探测Git |
| 归属/组件 | task project/components带最新version、--yes及reason；跨项目组件拒绝；有旧组件时换项目须update同时明确components；不改status/Session/Project revision |
| 七状态 | task status任意状态直接转到其他状态，含终态返回；同值当前CAS no-op，旧CAS拒绝；不结束/恢复Session、不清空Note/Checkpoint |
| 只读查询 | 工作台按项目/七状态/搜索筛选，不混入另一项目；清筛选不清归属；资料、规则、Note与复制上下文匹配最新快照 |
| 无现场能力 | 页面无代码现场/源码导航，CLI/HTTP退役入口拒绝；context不含worktreeStatus，不以资料路径展示实时证据 |
| CAS/分页 | 两调用方同revision/version只有一方写成功；失败重读判断，不自动覆盖；分页条件变化不能复用旧游标或混入旧结果 |
| 权限/兼容 | admin/reader页面均无业务写入口；reader写拒绝引用隔离合同测试；UI合同不匹配明确失败，不修改manifest数字冒充兼容 |
| 展示 | Markdown安全渲染，HTML不执行、内容图片不加载；空内容与失败不同；窄屏长路径/Note/Checkpoint无不可操作溢出 |

项目命令与严格DTO见 [项目合同](16-项目与上下文复用.md)；状态/Session分别见 [七状态](21-待上线任务状态.md)、[Session](09-AI-Session记录.md)。

## 结果与边界

每项结果需记录实际版本/环境、隔离数据标识、最短步骤、预期/实际和脱敏证据。前置满足但偏离预期为FAIL，缺环境/数据/权限为BLOCKED；不把未执行项填PASS。响应不确定先刷新核对是否写入，不重放。

自动化入口：application的projects/sources/project_profiles/task_maintenance/task_status/task_sessions、CLI/HTTP的projects、Web workspace/api及隔离浏览器smoke。测试文件存在不证明通过；源代码、契约测试、实际部署及人工业务验收分别判断。

服务启动、数据迁移、UI激活与正式切换须独立明确范围。完成上述查询或回归不自动将任务标done，不操作正式任务造验收数据。
