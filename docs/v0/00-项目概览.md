# Agent Steward V0 项目概览

Steward 是本地优先、用户主导的任务数据中心。AI 辅助理解需求、开发和记录，按用户明确指令操作状态；工具不编排开发/审核/上线流程，不把测试或交付推断为完成。

## 当前能力

- Task 目标、范围、验收、下一步、七种状态和 Note；最新 version CAS 防止过期覆盖。
- 显式 Session 关联与继续关系、Checkpoint、Session 记录导入和元数据观测；业务状态与 Session 生命周期独立。
- Project、组件、源码路径资料、项目资料、个人偏好及项目规则；独立 revision 与历史。
- 业务变更和 History 同事务保存；终态任务仍可维护信息、追加 Note，安全 Markdown 展示不改变原文。
- taskctl 提供 CLI，task-hook 投影显式绑定的元数据，taskd 提供 HTTP 与两套只读 Web 的服务合同。

SQLite Schema8 是本机业务状态权威；JSON envelope3、UI合同5、包格式1分别管理。普通连接只初始化空库或打开当前格式；旧库通过显式离线复制迁移。这些是源码合同，不证明安装、正式迁移或人工验收完成。

## 边界

不提供 Worktree 管理、主动 Git 查询、源码目录发现/导航/正文读取。源码路径仅是普通资料，不要求存在或通过 Git 验证。编码代理的源码/Git检查在 Steward 之外独立完成，登记资料不授权访问文件或执行操作。

不自动 claim/take-over/resume，不自动完成/取消任务；没有自动 commit/push、通用审批、多Agent编排或多机器共享数据库。测试显式使用隔离库和合成数据，不使用正式任务造测试数据。
