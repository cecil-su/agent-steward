# Agent Steward V0 项目概览

V0是本地优先的任务上下文工具。人类和AI通过`taskctl`创建、领取、维护和恢复Task；`task-hook`投影显式绑定的客户端事件元数据；`taskd`提供HTTP接口和只读Web工作台。

## 当前能力

- Task目标、范围、验收条件、状态、备注与关闭结果；Task version CAS防止过期快照覆盖。
- Session关联、继续关系和结构化Checkpoint；换窗口后重新读取任务及Git现场。
- Project、组件、源码登记、项目资料和有效规则上下文；各聚合使用独立revision。
- 本地已有分支的Worktree创建、状态、删除及非破坏性adopt/detach引用恢复。
- 显式Session文件导入、SHA-256去重、元数据查询和逻辑删除。
- 业务变更与History同事务保存；Git/SQLite部分完成返回明确诊断，不自动补偿。

SQLite Schema7是本机业务状态权威，Git和文件系统提供实时现场。JSON envelope2、UI合同4与包格式1分别管理。查询、Hook事件、Session结束和测试输出不构成领取、执行或关闭授权。

## 边界与入口

不提供自动commit/push、通用Operation/Approval、多Agent编排、跨机器共享数据库或自动验收。V1是独立设计，不从V0推定其实现状态。
