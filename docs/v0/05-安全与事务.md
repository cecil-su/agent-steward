# 安全与事务

## 信任与范围

本机单用户数据中心，由用户决定业务状态和显式Session操作。CLI不提供领域Owner/Approval模型；HTTP有admin/reader角色。默认本机直连信任本机用户/程序，代理或需隔离本机调用时必须使用 --require-local-auth。非回环HTTP不加密，网络风险见 [HTTP合同](11-Hook与HTTP合同.md)。

Steward不管理Worktree、不调用Git、不读取项目源码。源码路径仅是资料；保存、查询或删除资料不访问/删除该路径，不证明身份，也不授予执行权限。编码代理仍须独立保护用户现场，不以Steward状态代替Git/源码检查。

## SQLite与CAS

- Task/Session/Checkpoint/Note及History只经Application写入，不直接编辑SQLite。
- 普通连接仅打开Schema8或原子初始化空库，拒绝不兼容/非空未标记库；写事务取得锁后复核Schema。损坏库不自动删除、重建或覆盖。
- 数据库使用外键、WAL和有限busy timeout；业务写入使用短IMMEDIATE事务，不在其中执行宿主长操作。
- 已有Task mutation检查请求expectedVersion，Project/Rule用独立revision；History与业务共同提交/回滚。状态同值no-op也先检查CAS。
- 冲突、繁忙或响应丢失均需重新读取并判断，不自动用新版本重放旧请求。
- status可自由转换但仍有合法值、CAS、事务保障；不清空旧记录，不更改Session。终态不阻止Note或信息维护。
- 普通task context为READ_ONLY|NOFOLLOW/query_only连接，不建库、不改权限/journal_mode；读取WAL可能涉及SHM，不用immutable或忽略WAL伪装零活动。

## Session身份

claim仅显式登记当前Session，不是执行授权。尚不存在的ID才可创建；同一未结束当前Session在正确CAS下可no-op；其它历史/跨Task/已结束ID不能复用或重新激活。

已有当前Session时claim/resume必须明确take-over。resume来源须同Task，新ID与来源不同且未使用；continuedFrom保留旧记录，不伪造旧endedAt。session close结束当前Session时同事务清空关联，不改变业务状态。无自动超时/心跳回收，Hook生命周期事件不代替Session操作。

Checkpoint要求同任务未结束的当前Session，不以业务状态限制。没有当前Session不得为了写检查点隐式claim/resume。Session操作、测试和交付不自动标done/cancelled。

## 文件与路径

`application::path_safety`承担数据库、迁移及必要显式文件操作的非Git身份检查。已有路径取得规范路径/原生对象身份；目标路径从已有祖先解析，活跃身份与可序列化记录分开。Linux活跃身份用共享O_PATH句柄抑制对象删除后的inode复用，作用域结束关闭；持久身份摘要不能证明跨进程连续性，也不提供文件系统原子快照。

源码directoryPath只做有界绝对路径文本校验，不调用该身份机制。Session recordPath是显式外部记录引用，缺失时提示，不自动扫描记录目录。Session Import需要实际读取已明确提供的普通文件，与源码资料分开。

迁移有更严格的本地路径、sidecar、目录权限、停写及无覆盖发布要求，见 [隔离迁移](18-Schema7隔离导入与验证.md)。不可把源码资料允许的路径形式当作迁移文件访问许可。

## 隐私与权限

- 数据库无内容级加密保证；Task/Note/Checkpoint/History/Import禁止Token、Cookie、密码、授权头及隐藏推理。
- 数据放用户应用目录，不主动放共享目录或Git仓库。Unix目录0700，库/WAL/SHM不宽于0600；Windows用当前用户与必要系统主体的私有DACL。
- AppContainer仅可使用token明确给出的包SID；restricted token仅原样保留目标对象已有、父目录独立确认且与token非广泛restricted SID匹配的ACE，不按名称或候选数量猜测，不放行Everyone/广泛主体/capability SID。
- 检查默认/自定义父目录、数据库及WAL/SHM；无法证明安全时返回稳定权限告警或按入口拒绝。不因命令在打开库前失败而省略已有路径权限检查。
- Import仅在显式敏感内容确认后读取≤16MiB普通文件；有界缓冲区计算SHA-256，拒绝设备/目录/Socket/FIFO。没有自动秘密过滤保证。
- Import元数据查询不返回BLOB；删除用secure_delete并同事务写不含原文History，提交后尝试wal_checkpoint(TRUNCATE)。未完成时告警，不回滚逻辑删除；不保证SSD、外部备份/快照的物理擦除，不删除原文件。
- Hook只投影客户端实际提供的白名单元数据，丢弃正文/工具参数结果/自由错误，不写重试正文文件；事件不承载执行权。

## 不变量

Task ID不可改且不复用，taskKey只可首次设置；描述可暂缺、设置后不可清空，但没有done前完整性门槛。当前Session必须同Task且未结束；继续关系和Checkpoint/Note/History引用不能跨Task。旧closure/block字段不再与当前status耦合，旧History不重写。

信息维护需明确字段授权，部署/迁移/远程写入仍独立确认。保存记录、自动化测试通过或页面可访问均不构成业务验收。
