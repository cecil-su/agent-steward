# 服务使用与验收

当前源码Schema8、业务envelope3、UI合同5、包格式1；不表示正式实例已升级。普通启动只初始化空库或打开当前Schema，旧库须显式迁移，见 [隔离导入](18-Schema7隔离导入与验证.md)。

## 构建与隔离启动

```text
cargo build --workspace --locked
```

仅在获准的新隔离实例运行下列命令，TEST_DB/RUNTIME替换为专用绝对路径：

```text
taskd --bind 172.19.10.185 --port PORT --database TEST_DB --runtime-dir RUNTIME --no-open --require-local-auth
```

访问 `http://172.19.10.185:PORT`。该地址不可用先报告确认，不回退；端口占用失败，不静默换地址。程序默认回环监听/43123是产品默认值，本项目执行时须显式指定上述地址。通配、多播、广播不允许；Host/Origin严格匹配实际绑定地址/端口，不放宽CORS、不自动改防火墙。

安装全局程序、停止/替换服务、迁移正式库和UI激活均是独立操作，不能因构建成功自动执行。Windows入口见 [发行指南](../../distribution/windows/README.md)，源码不证明运行程序/数据库/UI的实际版本。

## 身份与网络

默认本机直连模式按真实TCP peer识别本机（回环或监听网卡IP直接来源），信任本机所有用户/程序；含转发头或缺peer不获得本机特权。不得通过代理/隧道/端口转发暴露该信任模式；隔离调用或代理必须使用--require-local-auth。

首次启动创建admin/reader凭据于私有runtime/identity，重启复用，终端只显示URL及凭据文件路径，不输出秘密。远程/严格模式要求凭据或Cookie；不要分发admin给只读设备。

严格模式自动打开浏览器时可通过120秒一次性连接码建立授权；码仅经fragment传递，页面立即清除，不记录完整链接。--no-open禁止自动打开。手工登录以请求头凭据建立30天HttpOnly/SameSite=Strict Cookie，私有browser-sessions.db只存哈希、角色、凭据绑定和到期时间，不将长期凭据放JS存储。

退出撤销当前Cookie，管理员可撤销当前origin全部浏览器授权；凭据轮换使旧绑定失效。本机免登录不因Cookie退出而撤销。当前HTTP及Cookie无Secure保护，局域网也不是加密连接；须限制网络访问。完整容量、路径/文件与隐私边界见 [HTTP合同](11-Hook与HTTP合同.md)。

## 工作台

1. 查询任务、七状态/项目筛选和分页；active排除done/cancelled。
2. 查看目标、范围、验收、Note、Checkpoint、项目资料、规则及历史关闭含义。Markdown安全渲染不改原文。
3. 查看Session继续关系、Hook与Import元数据；不显示源码或Git现场。
4. 复制最新任务上下文，保留错误/空内容/截断区别；查询不领取/恢复任务。
5. 业务写入使用CLI或管理员API；页面对全部角色只读，没有status/claim/close或其他业务写按钮。

## HTTP速查

认证：X-Steward-Token或浏览器Cookie；POST /api/connect使用X-Steward-Connect，一次性码不能调用业务接口。POST /api/login、/logout、/browser-sessions/revoke分别建立/撤销授权。GET /api/access给出角色、local及能力标记。

本机免认证或Cookie写请求要求精确Origin、X-Steward-CSRF:1；POST还要求JSON Content-Type。显式错误Token不回退Cookie。reader在业务写请求体解析前拒绝，认证登录/退出除外。无跨Origin/CORS旁路。

查询：

- GET /api/tasks?view=active|backlog|todo|in-progress|in-review|blocked|done|cancelled|recent，支持project/query/pageSize/cursor/status/taskKey/fields；view/status互斥。
- GET /api/tasks/:id、/context、/notes、/history。
- GET /api/sessions?taskId=:id、/api/sessions/:id、/imports、/events?after=0&limit=100。
- GET /api/projects及项目/组件/源码路径资料/History，见 [项目合同](16-项目与上下文复用.md)。
- GET /api/doctor只检查数据库与Session记录路径，不查Git。
- GET /api/events是SSE数据失效通知，不是业务事件重放；重连重新查询，不重放写请求。

业务命令：POST /api/commands/:command，严格JSON/未知字段拒绝。taskId为整数，expectedVersion必须来自调用方已读快照。

```json
{"taskId":1,"expectedVersion":3,"status":"in_review"}
```

上例用于task-status，任意状态直接转换，不改Session。task-create/update/retitle/note/claim/resume/checkpoint、session-bind/attach/close/import-add/import-remove、hook-clear及项目命令使用各自DTO；update/project/components要求confirmed=true与非空reason，Session关闭/Import删除/Hook清除及源码资料解除仍按各自确认合同，Import读取要求confirmSensitiveContentReviewed=true。

旧task-close/block/unblock/pending-release/continue、Worktree接口、目录探测与源码导航/读取接口已移除，不提供静默别名。七状态和Session解耦见 [状态合同](21-待上线任务状态.md)。

所有业务响应使用schemaVersion3/ok/data/warnings/error。400输入、401认证、403来源/只读拒绝、404不存在、409冲突、503繁忙、500其他错误。不解析自然语言错误；HTTP取消不保证已经开始的SQLite工作停止或回滚，响应不确定先查询核对。

## Hook

必须先显式建立本地Session及外部绑定，再配置宿主，不能根据cwd/窗口/最新任务推测。通用适配器接受≤256KiB宿主JSON，只投影稳定eventId/kind/occurredAt及绑定标识到≤16KiB标准事件。正文/工具参数结果等丢弃，无落盘重试队列；busy最多两次有界重试，其他失败非零退出并显示风险。

事件DTO仍schemaVersion1；task-hook宿主输出协议不随CLI envelope3改形。标准事件按(sessionId,eventId)去重，满10,000条（含墓碑）停止接收新ID。closed/resumed等不改变Task/Session生命周期；清除使用Task CAS并保留去重墓碑。详细命令和原生接入见 [HTTP合同](11-Hook与HTTP合同.md)、[集成指南](../../integrations/README.md)。

## UI采用与验证

不指定--ui-root使用内嵌快照；外置包必须与UI合同5匹配，实际采用以/ui/status为准，不能仅改manifest号。包更新不修改任务库或替代后端Schema升级，详见 [UI发布](14-UI独立发布.md)。

测试入口和当前已执行范围见 [测试与验收](08-测试与验收.md)。真实浏览器、客户端信任/模型链路、目标平台与正式数据分别核实；源码或测试通过不是部署与业务验收。
