# 七种任务状态

## 语义与唯一入口

Steward 记录用户选择的业务状态，不执行开发流程编排。

| 状态 | 含义 |
| --- | --- |
| backlog | 暂不开始 |
| todo | 等待开始；创建默认 |
| in_progress | 执行中 |
| in_review | 已交付，等待审核或验收 |
| blocked | 受阻 |
| done | 已完成 |
| cancelled | 不再推进 |

七状态之间可按用户指令任意转换，包括 done/cancelled 返回其他状态。没有领取、完整描述、Checkpoint、阻塞原因、审核或上线前置条件。测试通过或 Agent 交付不自动等于 done。

```text
taskctl --database TEST_DB --json task status TASK in_review --if-version VERSION
```

HTTP：`POST /api/commands/task-status`

```json
{"taskId":1,"expectedVersion":3,"status":"in_review"}
```

status 是唯一业务状态变更入口。旧 task block/unblock/pending-release/continue/close 命令及对应 HTTP 命令已移除，不作为隐式兼容别名。需要说明阻塞、取消或验收依据时可记录 Note，不把说明设为状态转换门槛。

## CAS、事务与历史

- 合法值校验后，在 IMMEDIATE 事务中读取 Task、检查请求 expectedVersion。
- 同状态请求在 CAS 成功后 no-op，不递增 version、不修改 updatedAt、不写 History；旧版本仍冲突。
- 实际转换只修改 status/version/updatedAt，同事务写 `task.status_changed`，payload 为 previousStatus/status，sessionId 为原当前 Session 或 null。失败全部回滚。
- 不修改 nextStep、Note、Checkpoint、项目、组件、Session 或旧关闭/阻塞字段。旧 History 不回填、不改写。
- update/retitle/note/checkpoint、claim/resume、Session close 与 Hook 不改变任务业务状态。

## Session 独立生命周期

任意任务状态都可执行显式 Session 操作。claim/resume 仍检查 CAS、Session ID、归属和接管；Checkpoint 要求尚未结束的同任务当前 Session。status 不领取、接管、恢复或结束 Session；done/cancelled 也可以保留当前 Session。Session close 仅结束指定 Session，当前关联才被清空，不改变 status。

没有当前 Session 时可以显式 claim 创建全新独立会话，或显式 resume 指定历史来源；不得自动选择、激活或恢复旧 Session。详见 [Session 合同](09-AI-Session记录.md)。

## 查询与展示

`--status` 使用七种 snake_case 值或 active；active 排除 done/cancelled。`--view` 为 backlog/todo/in-progress/in-review/blocked/done/cancelled/active/recent，recent 不限制状态；view/status 互斥。HTTP 使用同名查询参数，两套 Web 均只读展示，不增加业务写入口。

旧 closureOutcome/closureReason/closedAt 和 blockReason/blockRecovery 作为历史字段保留，无当前状态约束；不能把旧关闭结果或阻塞原因冒充当前状态。新 done/cancelled 不生成旧式关闭结果。

## 迁移与验证

旧 open→todo、pending_release→in_review、in_progress/blocked 保持；closed+completed→done，closed+cancelled/partial/superseded→cancelled。原关闭结果、原因、时间和旧 History 保留；不凭文本推断状态、不恢复 Session。

Schema8、envelope3、UI合同5、包格式1。显式迁移及源格式区别见 [隔离导入](18-Schema7隔离导入与验证.md)。这些版本是源码合同，不证明正式库或运行实例已升级。
