测试必须显式使用临时数据库、合成Task/Project/Session和必要临时文件，不访问默认库、不用正式任务造数据。Steward不需要临时Git仓库验证当前业务能力；旧格式迁移夹具中的Git引用只是数据，不执行Git或读源码。

## 任务状态与Session回归

- 创建最小Task为todo/version1，不要求完整描述或项目。
- 七状态49种有序组合均可调用status；42种实际转换只改status/version/updatedAt，7种同值CAS后no-op。
- 旧CAS、非法状态/字段、缺任务、并发写和History故障均不产生部分写入；旧History/关闭结果/阻塞记录、Session、Note、Checkpoint/历史gitHead不被状态变化清除。
- claim/resume/attach/bind/close/checkpoint/import覆盖七状态；业务status不变，保留新ID、同Task、未结束当前Session、显式take-over与CAS限制。
- 历史Session不能重新激活，无当前Session可显式claim或指定来源resume；状态变化/只读上下文/宿主事件不隐式执行这些动作。
- Note适用于全部状态和无当前Session的终态任务，原文及历史关闭结果保留；信息维护仍需明确确认/依据，项目组件关联原子修改。
- Hook绑定、迟到/乱序/重复/冲突/墓碑/容量不改变业务或Session生命周期；敏感正文不入库。

## 存储、接口与页面

- 空库原子初始化、并发初始化、旧Schema拒绝、只读context不建库/不改WAL、外键、ID高水位、版本/CAS、事务回滚和损坏JSON拒绝。
- Session Import≤16MiB普通文件、敏感确认、哈希去重、BLOB不经查询返回、逻辑删除及物理擦除警告；Unix FIFO等平台项须在对应平台运行。
- CLI/HTTP envelope3，七状态与Task20字段合同；JSON严格输入、大小/UTF-8边界、分页/筛选/字段投影及稳定错误。
- 退役Worktree、here、源码context/resolve入口及字段不再可用；源码路径只作文本资料，不检查存在性、不读取源码/Git。doctor仅数据库及Session记录路径诊断。
- HTTP Host/Origin/CSRF、admin/reader、Cookie到期/撤销、请求并发与取消边界；reader在业务写体解析前拒绝。
- 两套页面均只读，七状态标签/筛选、历史关闭结果、资料/规则、Note/Checkpoint安全Markdown和完整上下文复制；空值/错误/截断分开。
- UI合同5/包格式1：版本固定资源、兼容拒绝、SSE重读不重放写请求、包切换不丢失用户输入；旧合同包不能只改manifest号冒充兼容。
