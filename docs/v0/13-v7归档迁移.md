# archive-v7 归档导入

`database import-v7`处理独立旧归档格式，不是user_version=7输入，不是普通打开自动升级或任意SQLite合并工具。目标为Schema8。

## 输入与前置

- 源user_version=0、schema_migrations含版本1–7，表列及布局匹配；全部Task为旧closed，无当前Session及Repository/Worktree绑定，worktree_path_key只能NULL。
- 歧义taskKey、未知表/列、无效数据、完整性/外键损坏拒绝。不修改源版本号冒充兼容。
- 先停全部源写入者，通过SQLite Backup API取得包含已提交WAL的一致快照，不只复制运行中主文件。
- 源/目标须显式绝对本地路径与--yes，源及sidecar普通文件，不接受链接/目录；目标及-wal/-shm/-journal全部不存在，含悬空链接。
- 目标父目录私有且由操作者控制，不覆盖、不合并、不改已有目录权限。路径、停写、身份复核、暂存清理与无覆盖发布限制见 [隔离迁移安全合同](18-Schema7隔离导入与验证.md)。

```text
CLI --json database import-v7 --help
CLI --database NEW_DB --json --yes database import-v7 --source SOURCE
```

仅使用核验程序与合成/获准停写快照，NEW_DB必须是不存在的隔离目标。

## 复制与转换

Service::import_legacy_v7以READ_ONLY/query_only和固定读事务打开源，校验格式、Task范围、quick_check和外键；同目录私有暂存库初始化Schema8并单事务复制Task、Session、Checkpoint、Note、History、Import。

- closed+completed→done，closed+partial/cancelled/superseded→cancelled。原closure_outcome/closure_reason/closed_at及其他保留字段原样保存，不丢失部分完成/替代含义。
- 保留ID/version/时间、Session继续关系及endedAt、Checkpoint历史git_head、JSON原文、History ID/sequence/changeType/payload、Import BLOB及高水位；转换投影逐字段核验。
- schema_migrations、NULL的worktree_path_key及退役Task仓库字段不进入目标；不重写History中的旧字段，不产生新业务History、不恢复Session。
- 目标session_events及项目/组件/源码资料/项目资料/规则相关表为空；project_id为空，不按文本猜归属。

完整性、外键及应用读取校验后关闭并刷盘，复核源/父目录身份与目标占用，以hard link无覆盖发布；不支持则失败，不回退覆盖。固定读事务和身份复核不证明停写，读取WAL可能涉及SHM。

## 失败、验证与切换

失败只清理本次暂存，不发布部分目标、不修改源或已有目标；进程中断残留不自动采纳/清理。命令不安装、不改默认库、不启停服务。

显式指定新库核对Task状态映射、旧结果、Session、Note、History、Import及ID高水位；doctor涉及记录路径元数据，路径未获准时不执行。测试入口：application的migration与CLI migration_contract，全部使用合成隔离库。

其他源使用 [对应入口](18-Schema7隔离导入与验证.md)。正式切换须独立停写/备份/核验与配套程序确认；新库接受写入后无自动回退或反向合并，不能直接覆盖备份或只降级程序。源码和复制成功不证明正式部署、断电耐久性或业务验收。
