# 只读工作台

## 架构

```text
React Web（web/src）
       │ 同源HTTP
       ▼
Rust taskd / UiStore
       │
Application Service
       ├─ SQLite
       └─ Git / 文件系统
```

当前内嵌资源来自`crates/server/web-readonly`；`--ui-root`可托管兼容的三文件外置包。工作台不解析CLI文本，不直接访问SQLite，不需要独立前端服务或Node运行环境。UI合同4、包格式1，完整发布限制见[UI独立发布](14-UI独立发布.md)。

CLI、Hook和taskd共用Application及本机数据库。SSE通知已提交数据变化后，页面重新读取快照，不重放写请求。外部Git文件变化须主动刷新。

## 页面范围

- 任务列表：状态/项目/搜索筛选、分页、当前Session、阻塞、下一步和更新时间。
- 任务详情：目标、范围、验收、项目资料、有效规则、Notes、Checkpoint、关闭结果和History。
- Session：来源、外部ID、continuedFrom、记录路径、Hook观测和Import元数据；不渲染Import BLOB。
- 代码现场：数据库登记路径与实时Git状态分开展示；路径消失时保留登记及诊断。
- 项目：资料、组件、源码根、关联任务与只读上下文。
- 上下文复制：完整读取任务与规则；缺字段、查询失败或截断不能伪装成完整成功。

所有角色页面均无业务新建、编辑、领取、关闭、清除、Import删除或Worktree写入口。业务维护通过CLI；HTTP管理员写合同仍存在，隐藏按钮不是后端权限保护。登录、退出和授权撤销属于身份操作，不是业务维护。

## 身份与错误边界

默认绑定127.0.0.1:43123，可显式绑定本机IPv4。默认本机直连免凭据，信任本机用户和程序；代理或需隔离本机调用时使用`--require-local-auth`。远程/严格模式采用凭据或30天浏览器Cookie授权。Host/Origin、CSRF、角色和明文HTTP风险见[Hook与HTTP合同](11-Hook与HTTP合同.md)、[服务使用指南](12-服务使用与验收.md)。

- reader只能读取业务接口，后端在解析业务写请求体前拒绝。
- API查询失败、Git观察失败、分页失败和更新检查失败保持明确，不混入其他查询结果或伪造clean状态。
- 页面版本切换不得丢失未应用搜索、登录输入或待复制内容；资源版本固定，不混用不同包的JS/CSS。
- Session结束、Hook事件、摘要及测试文本不能显示成用户验收完成。
