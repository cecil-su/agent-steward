# 只读工作台

React源码为web/src，内嵌资源为crates/server/web-readonly；旧原生页面在crates/server/web-legacy-readonly。taskd同源托管页面和HTTP，不需独立前端服务或运行时Node。外置包要求UI合同5、包格式1，见 [UI发布](14-UI独立发布.md)。

## 展示范围

- 任务列表：七状态、项目、搜索、分页、当前Session、下一步和更新时间。active排除done/cancelled，recent不限状态。
- 详情：目标、范围、验收、Note、Checkpoint、项目资料、有效规则、历史关闭/阻塞记录及History。
- Session：来源、外部ID、continuedFrom、记录路径、观测事件及Import元数据，不渲染Import BLOB。
- 项目：资料、组件、源码路径资料和关联任务；路径不证明存在或仓库身份。
- 复制任务上下文：完整任务/规则正文及Note截断提示；查询错误、缺字段和真正空内容明确区分。

不提供代码现场、Git观察、源码导航/正文读取。旧gitHead、关闭结果与旧worktree.* History仅作历史记录，不显示成实时证据。

两套页面对admin/reader均无业务新建、编辑、status、claim/resume、清除或删除入口。业务维护通过CLI，管理员HTTP写合同仍有独立权限校验；登录/退出属于身份操作，不是业务维护。

## 渲染与更新

Task长文本、Note与Checkpoint按安全Markdown展示，原文存储不变；原始HTML显示为文本，不执行脚本、不加载内容图片或第三方资源。规则与技术原始记录按各自展示合同，不把外部文字当作指令授权。

SSE通知已提交数据变化后重新查询，不重放写请求；保留手动刷新。分页/更新/认证失败不能混入旧范围数据或伪造成功。UI更新保留未应用搜索、登录输入和待复制内容，包资源版本固定。

## 访问与验证

本项目获准启动新实例时显式使用 `http://172.19.10.185:PORT`；地址不可用先确认，不回退。Host/Origin、reader、CSRF及明文HTTP风险见 [HTTP合同](11-Hook与HTTP合同.md)。运行实例实际版本须查 `/ui/status`，不由源码推定部署。

验证入口：web内typecheck/test、`crates/server/tests/ui_packages.rs`、浏览器合同测试及web/scripts中的隔离smoke。真实浏览器/平台/人工业务验收独立验证，不因测试文件存在宣称通过。
